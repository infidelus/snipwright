# Snipwright - Python dependencies
#
# Install with:  pip install -r requirements.txt
#
# Every package is held to what Snipwright has been tested with.  Most take
# a range that admits bug-fix releases of the tested version and nothing
# newer: numpy 2.5.x, PySide6 6.11.x, tqdm 4.x and bitarray 3.x (bitstring's
# own limit).  PyAV's range covers the two major versions tested (18.1.0 and
# 19.0.1), leaves out 19.0.0, which was never tested, and stops short of 20.
# bitstring and tibs stay LOCKED to one version each: bitstring decides which
# tibs it will accept, so letting bitstring move on its own could ask for a
# tibs the lock forbids, and the install would fail.  Each range ends its
# comment with "tested: <versions>", which the About box and
# dev/scripts/check-dependency-updates.py compare against.
# Without limits pip installs the newest release the moment it is published,
# and on 29 September 2026 that was PyAV 19.0.0: it removed an option
# Snipwright uses when opening every recording, so any install from that day
# on could not export anything.  A new version goes in here only after it
# has been tried against Snipwright, never automatically.
#
# These versions need Python 3.12, 3.13 or 3.14 (numpy 2.5.3 and PyAV 19
# need 3.12 or newer; PySide6 6.11.2 stops at 3.14).  The installers check for that range,
# so change it there too if a new version here moves it.
#
# The same list is repeated in src/packaging/install-linux.sh and
# install-windows.ps1, which use it if this file is missing.  Keep all three
# in step.  dev/scripts/check-dependency-updates.py reports newer releases.

PySide6>=6.11.2,<6.12  # Qt 6 GUI toolkit (the interface); tested: 6.11.2
av>=18.1.0,!=19.0.0,<20  # PyAV - decoding/muxing for the cutting engine; ships its own FFmpeg (18.1: 8.1.2, 19.0.1: 9.0.2); tested: 18.1.0, 19.0.1
numpy>=2.5.3,<2.6    # array maths used during cutting and by the advert detector; tested: 2.5.3
bitstring==4.4.0     # bit-level parsing of the broadcast streams
bitarray>=3.11.0,<4  # used by bitstring; tested: 3.11.0
tibs==0.5.7          # used by bitstring
tqdm>=4.70.1,<5      # progress reporting in the cutting engine; tested: 4.70.1
